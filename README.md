# Kho gói CX-5 (cài qua Wi-Fi từ iPhone)

Kho tĩnh cho trang "Cài đặt gói" chạy trên CMU Mazda (http://192.168.100.1:48080).

- `index.json`: danh sách gói dùng cho mọi xe
- `goi/*.cxpkg`: gói đã ký số (RSA-2048). Chỉ xe đã cài agent của người phát hành mới cài được.
- `xe/<mã xe>/`: gói riêng cho từng xe

Không có mã nguồn hay khoá bí mật trong repo này.
